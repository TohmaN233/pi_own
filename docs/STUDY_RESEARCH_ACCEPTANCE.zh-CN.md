# Study & Research 人工验收

记录 commit、系统、浏览器、Node、Python、Provider/Model；使用小型测试目录，不混入凭据。
本清单是待人工执行的步骤，不是已经完成的教学效果证明。

## 先走一条学习闭环
- [ ] 创建一个学习项目并选择目录。论文、教材章节和代码出现在元数据清单，原文件没有被改写。
- [ ] 切入模式后，实际工具含 `study_research`、`math_visualization`，不因为学习而启用任意 shell/write。
- [ ] 请求生成限定范围的路线图；先备知识、符号、定义、主贡献、证明/实现节点、疑点均可查看。
- [ ] 对一篇故意有错的短文，例如“所有连续函数都在实数域上有界”，Agent 不应无条件接受作者断言；指出可能反例并解释适用条件。
- [ ] 选择一个证明/实现节点，按你的问题逐步讲解，并能打开实际来源。模型自信不是通过标准。
- [ ] 记一条带公式的用户笔记，再让 Agent 保存一条建议。两者作者不同，Agent不能覆盖你的笔记。
- [ ] 提交自己的解释，学习记录保留原文；系统不凭聊天次数给出伪精确掌握度。
- [ ] 刷新、重启、打开项目中的另一对话，确认同一资料/笔记可恢复，而对话本身独立。

## Research 与实际代码
- [ ] 方向具体对应论文局限/节点；写清价值、最简单替代、所需证据、新颖性尚待核查。
- [ ] 实验计划有明确假设、基线、消融、指标、划分、seed、成功阈值与失败解释。
- [ ] 编辑Python或JavaScript代码，未保存或未批准不能运行；默认执行关闭。
- [ ] 明确信任本地代码并启用环境开关后，保存→批准→手动运行，看到真实stdout/stderr和退出状态。
- [ ] 一次批准不能重放；改代码/来源/地图/方案后旧批准无效。
- [ ] 超时、输出过量、解释器缺失都明确报告，不能显示成功。

## 两个模式共享的图形
- [ ] Study中生成曲线，缩放/重置可用；修改系数确实改变图形。
- [ ] 生成3D曲面/点云，拖动旋转能改变视角；无WebGL时显示明确限制及数值数据。
- [ ] 切到备课工作区，同一个数学面板可用，原有可视化列表仍保留。
- [ ] 课程/Assignment/学习项目之间不能读取对方图形ID；切出模式后专用工具退出。
- [ ] 随意加入HTML、JavaScript、NaN或过多点数时被拒绝。

## 暂不当作故障
完整终端/GPU运行、PDF坐标批注、任意TeX编译导出、形式化证明认证、已查新的保证、自动科研循环、自动将图插入某一课件页，均不是本期范围。

失败回报：步骤、commit、预期/实际、完整报错、截图、重启是否复现。跨项目泄漏、用户笔记被覆盖或未经批准执行时先停用真实资料。
