# 论文全文学习地图

后台阅读会先为每个固定论文片段保存独立、带来源定位的 Pi 报告。`paper-map` 不读取原始全文，也不复用父对话；它只接收这些报告的受限投影、哈希和覆盖事实。

地图固定包含五部分：核心问题、主要贡献、假设与符号、论证与依赖、限制与未解决问题。最后一部分和报告的 `unresolved` 都不能被解释为数学验证。阅读到某个论断不等于已经证明或核验它。

长文采用归约树。每个归约任务至多包含四份报告且总输入不超过 140 KiB；上层仅引用下层报告哈希，因而不会把全文反复放入模型上下文。每份地图报告保留其直接输入报告引用，沿这些边可追溯到原始分段报告。

当同一阅读快照的全部分段都进入终态时，可信后台 worker 自动入队下一层归约。失败、取消、需要处理、没有报告和超过归约边界的报告会出现在 `coverage` 中；其余已完成报告可形成明确标为“部分”的地图。系统不会为了凑齐地图而截断或忽略这些状态。

地图提交时再次检查所有源版本仍为当前版本。源文件更新、重新阅读某个分段或更换报告哈希会形成新的 `rootInputHash`。旧地图和原始 Pi JSONL 报告仍可审计，但 UI 不会把它们标为当前版本。相同输入快照的归约调度幂等；重启后队列中的哈希绑定仍用于恢复。

`paper-map` 是学习流程，不会启动测验、研究方向或父 Pi 对话中的自动模型轮次。
