# Study & Research 地基使用说明

入口：普通 Pi 会话的模式栏 → **Study & Research**，或 `/study-research`。
新工作区不复用学生课程/备课会话的项目绑定；同一文件夹可以作为不同项目的资料，但数据不会因此自动共享。

## 第一条可用流程

1. 更新当前代码并按原启动器启动 Pi Web。在工作区创建学习项目，选择论文/教材/代码所在文件夹。
2. 扫描只建立文件清单，不执行代码，不把整个目录塞给模型。`.git`、`node_modules`、常见密钥目录/文件和符号链接被排除。这不是数据防泄漏产品：不要把私密凭据混在资料目录。
3. 打开资料文本；PDF 和原文件预览复用已有查看器。提取文本的位置是“提取行”，不是 PDF 页坐标。图片/无适配器的二进制材料不能被假装读懂。
4. 配置你的 Pi Provider/Model，点击“生成／修订阅读地图”。指定教材章节或论文范围。Agent 使用真实 `study_research` 工具，保存背景、记号/定义、贡献故事、依赖图、证明/实现分析、具体理解检查和疑点。
5. 选择一个节点，要求逐步讲解。`unchecked / argument-given / gap / candidate-error` 是论证状态，不是形式化认证；学习进度只能由你结合一次具体尝试记录。
6. 用户与 Agent 的笔记分别署名。可使用 `$...$`、`$$...$$` 与代码块。在资料段中粘贴精确引句，可为笔记加上源文件摘要和行范围。地图与笔记可导出 Markdown。
7. “研究方案”根据具体节点或疑点提出方向；新颖性默认未建立。实验必须说明假设、对照、消融、指标、数据划分、seed、预算、成功和失败解释。
8. 代码实验台可编辑 Python / JavaScript。保存修订、批准具体版本、再明确点击运行。Agent 没有 approve/run 工具；每个批准只能用一次。修改代码、来源、地图或研究方案会使旧批准失效。
9. 打开“2D / 3D 可视化”，选择预设或修改受限数值 JSON。共享 `math_visualization` 工具也可以生成图。缩放/旋转/重置由本地固定 Plotly viewer 完成，不运行模型生成的网页脚本。

## 可复用与信任边界

复用现有原生 Pi AgentSession、JSONL、同页 ChatWindow、项目/多会话组织、Markdown/KaTeX、PDF.js和 LearningHarness 的 SQLite/WAL 所有者。新增状态在同一数据库中，原聊天仍只有一份。两种模式共享一个物理数学插件；课程 Assignment 和 Study 项目分别限定图形作用域。

默认不执行代码。明确接受可信本地代码风险后，在**启动服务前**设置：

```powershell
$env:PI_STUDY_TRUSTED_CODE = "1"
# Windows 上 python3 不可用时，指定已安装的 Python 解释器：
$env:PI_STUDY_PYTHON_PATH = "C:\path\to\python.exe"
.\start-learning-harness.ps1
```

这不是任意代码安全沙箱。子进程仍具有本机账户的文件/网络权限。限制为独立临时目录、无 shell 解析、过滤继承环境、最多30秒和256KiB合并输出。源文件读取接口不修改你的目录，但你批准的任意代码仍可能访问机器其他路径。只执行你审阅并信任的代码；不为不可信用户提供服务。

代码实验台不是完整 PTY：不支持交互式 stdin、终端会话、自动安装依赖、自动租算力或长期/GPU训练。Python 使用指定解释器的已有环境（隔离启动）；不复制原项目环境或自动导入其模块。

## 当前可视化

- 多项式曲线、2D/3D散点、二维矩阵变换、鞍面/抛物面/Gaussian参数曲面。
- 本地锁定 `plotly.js-strict-dist-min@4.1.0`；交互式2D缩放和3D旋转。
- 固定数值规格、有上限的点数/采样、版本/数据Hash、按项目保存、JSON导出。
- 不支持自定义JavaScript、任意Plotly配置、外部数据URL或自动插入课件。
- 没有 WebGL 时明确提示并保留数值数据，不把空白3D算作成功。

## 已有基础与下一阶段

**地基**：目录和来源身份、阅读DAG、批判性状态、来源笔记、用户进度记录、研究/实验方案、一用批准与真实短程序、共享图形工具及页面、真实Pi资源激活、持久恢复与回归。

**后续**：PDF选区/坐标高亮与双向批注、复杂公式/表格结构提取、形式化证明器、外部文献检索回执、深层代码符号链接、持久产物目录与多seed统计、PTY/Notebook、OS沙箱、Manim动画/高级3D场景、可视化自动插入Beamer、长期自适应教学。没有把这些列入本次完成项。

开源考据、采用/排除理由与分期：`STUDY_RESEARCH_PLAN.zh-CN.md`。机器可读来源登记：`STUDY_RESEARCH_SOURCES.json`。自动测试证明的是软件边界与实际执行，不证明模型已经完全理解论文，也不证明研究想法新颖。
