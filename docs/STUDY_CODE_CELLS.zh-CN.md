# Study / Research 代码单元

`StudyCodeCells` 由现有 `LearningHarness` 注入同一个 SQLite 连接，保存 R/Python 代码单元的不可变版本。这里不启动进程，也不建立另一套会话或产品数据库。

每次保存固定代码、参数、来源绑定和各自的 hash。修改必须携带打开编辑器时观察到的 cell revision；冲突保留前端编辑内容，不自动覆盖新版本。输入使用已登记的 sourceId/hash 和独立运行时文件名，Agent 不接受任意本机路径。参数必须是有界、有限数值的普通 JSON，拒绝 Date、Map、函数和非有限值。

运行接线通过 `bindRunFromTrustedAdmission`：受信任协调器应在入队的同一外层事务中调用它，核对当前会话、可信执行来源以及代码／参数／输入／环境的精确运行 manifest。保存后的代码编辑不改变该运行快照；重试同一 task 只返回原快照。该方法不代表任务已经启动。

首次绑定只接受当前来源版本，并核对学习准入的语言与用途。已绑定 task 的重放在来源后续更新后仍返回原快照；尚未绑定的旧来源代码单元会明确拒绝，必须重新选择来源版本后再运行。实际字节快照还需执行适配器在入队事务前准备并核验，不能仅凭此数据库绑定宣称输入文件已经冻结。

前端 `/study` 支持创建和编辑代码单元，Agent 使用 `study_paper.save_cell`。保存不生成执行任务，不编造计算结果。实际运行按钮、环境选择、stdout/stderr、图表和取消入口仍须与监督服务接通后验证，当前不是完整执行能力。

验证：`node --test scripts/study-code-cells.test.mjs`；API 回归包含创建、更新、陈旧版本拒绝、保存不生成任务。原始 Pi JSONL 与模型运行独立，API 测试不调用模型。
