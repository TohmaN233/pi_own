# Harness 验收清单：备课优先

以 main 上的真实合并提交为准。本文件列出验收步骤，不是已经通过的人工测试记录。
不要把文件存在或勾选框当成 CI 证据。旧聊天中的完成声明不能覆盖仓库实际状态。

## X：先完成一节课

- [ ] 单课计划的“打开教案”在独立可滚动页面排版显示全文。可编辑环节、练习和资料，关闭/重开恢复未保存编辑；保存后新版本持久保留并可在此批准。并发生成新版时显示冲突，原课程有明确返回入口。

- [ ] 批准学期和单课计划后，给课程文件夹新增参考题、刷新清单或改教师署名，不要求重新生成大纲；新增题目可按需用于单课计划，旧计划及审批记录不变。修改课时、目标或周次后出现具体规划冲突。
- [ ] 填写“额外要求”后，分析/学期/所选单课/Beamer 任务的实际 Pi 消息包含该内容；直接“发送给 Agent”只发送输入内容，失败不清空。

- [ ] 已有会话的“技能”和教师“Skills 与提示词”中，进入“技能库 · 添加与市场 → 添加技能”，可搜索市场或从地址添加。完整技能目录安装到项目 `skills/`，页面显示实际路径；检查更新和更新仍可用且更新留在原库。安装后当前模式出现新的可选技能，默认不启用，原有组合不变。

- [ ] 进入已有课程后，左侧课程操作与右侧原 Pi 对话同时可见；分析任务的输出直接出现在右侧。窄屏可以上下滚动，课程区和聊天区均有可用滚轮。
- [ ] 在右侧“Skills 与提示词”和 Pi 设置的“技能”页看到项目 `skills/` 的完整原文、当前组合与实际加载状态；关闭可选 Skill 后，运行时提示词不再含其原文。必需 Skill 不允许关闭。
- [ ] 修改当前模式提示词并保存，下一次模型调用实际使用该文本；切换学习/练习或普通模式再切回，恢复该模式的修改，重启后仍保留。
- [ ] 已激活 Mode Pack 的会话可切换模型和推理等级，sessionId、已有消息与课程绑定保持不变。模型列表含 `openai-codex/gpt-6-astra`（账号可用且模型范围允许时）。

- [ ] 更新 main；按 docs/COURSE_BUILDER.md 启动，打开普通 Pi 会话。
- [ ] 从空对话点击“备课 · 继续已有课程”，选择旧课程直接恢复原会话与进度，侧栏不增加空对话；休眠或旧 Skills 不阻止读取与编辑项目。
- [ ] 直接打开 `/course-builder`，无需会话即可填表并点击创建；双击或重复请求只产生同一工作区。刷新保留新课程草稿，文件载入能恢复全部字段；编号 `MATH 101/201` 按预览保存为 `MATH-101-201`。
- [ ] 首次设置显示教师与课程字段表单而非原始 JSON；刷新后本机教师偏好能带入新课程默认值。
- [ ] “模式与 Skills”页面可使用鼠标滚轮滚动；备课资料区提供“链接本地资料文件夹”，并打开可滚动、有返回/关闭控制的本机目录选择器。
- [ ] 文件夹绑定保留安全的相对子目录身份，不按扩展名过滤，不在绑定时抽取全部正文；Agent 通过有界 `read_material` 按需读取。未知二进制保留在清单并明确报告暂无文本解析器。
- [ ] 链接后的文件被改动、移走或经符号链接越出所选根目录时，Host 明确拒绝读取并记录错误；上传文件副本仍执行 100 文件/64 MiB 上限。
- [ ] 建立两个 Assignment 并分别选择专属资料文件夹；每个作业只显示和读取自己的资料，课程 `read_material` 与另一个 Assignment 的读取动作均被 Host 拒绝。
- [ ] Assignment 资料重新索引、草案生成和教师审批只提高该 Assignment 的 revision，不改变课程项目 revision，也不使现有学期/单课计划过期。

- [ ] 任一 Required SKILL.md 缺失、被改写或正文在系统提示中不完整时激活失败；只有资源名称或 marker 不算加载成功。
- [ ] 工具中只有专用 course_builder，没有因备课而开放任意 shell/write/edit。
- [ ] 课程标题下点击“编辑课程设置”，修改学期容量、目标、受众、语言及 Beamer 配置，保存刷新后仍存在；两个窗口提交同一旧修订时第二个明确报冲突。
- [ ] 导入旧 PPTX，抽查真实页序、文本及备注；不要求母版/动画/图片语义复刻。
- [ ] 导入 PDF、TeX/Markdown；文件原文和 Hash 可追溯。坏批次不能留下部分材料。
- [ ] “分析资料”会调用真实 Agent，保存主题链、重复、跳步、符号不一致和练习机会。
- [ ] 生成学期计划，覆盖课次和目标，标明资料来源与教学设计理由。
- [ ] 未批准时不能保存下游正式单课计划；Agent 自行 approve/accept 被拒绝。
- [ ] Assignment Agent 保存作业说明、任务、提交物、评分标准、解题提示与实际来源 ID 后停止；教师在工作区审批，旧 revision 审批被拒绝。
- [ ] 教师要求修改后生成新草案；旧 revision 操作被拒绝。批准正确学期计划。
- [ ] 在“选择备课课次”选择任意课次（如第 3 周第 2 次）生成单课计划：时间、目标、学生动作、worked example、理解检查和资料关联完整。核对 Agent 收到的周次和主题不是固定第一课。

- [ ] 备课模式下切换普通工具预设、PowerShell/Bash 并重新加载，实际工具及页面状态一致，备课 Skills/专用工具仍在；失败时显示原因。
- [ ] Pi 主界面原有侧栏顶部“＋ 新建”进入空白普通 Pi 对话，原课程和备课对话保留，新会话无课程/Mode Pack/历史消息继承。

## 失败报告

- [ ] 保存学期计划后顶部出现“审阅学期计划 · rN”，点击及直接打开链接均定位正文；36 个时段可以逐项或全部展开，学习目标、活动、证据、资料等完整可读。
- [ ] 在学期计划下填写修改意见并点击“要求修改”，请求携带当前计划 ID 和 revision；仅浏览计划绝不能自动批准。
- [ ] “要求修改”自动向 Agent 发送意见和目标版本，重复请求不重复发；发送失败明确显示并可重试，未保存修改稿不显示完成，新稿保存后显示完成但不自动批准。
- [ ] 对话审阅提示仅第一次生成学期计划时出现，可用 × 关闭；刷新、切换课程内对话、保存新版本或单课均不再次弹出，顶部审阅入口始终可用。

- [ ] 点击 Agent 消息中的 `.md` 本地链接，在右侧显示正文，当前课程和对话保留；Windows 盘符路径同样可用。
- [ ] 作业 Markdown、TeX、日志等产物链接打开侧栏预览，可切换源码或下载；关闭按钮及 Escape 均可返回，长文可滚动。
- [ ] 无权读取或不存在的文件明确显示错误，不伪造内容，也不因预览自动将资料全文放入模型上下文。

- [ ] 从备课 Agent 上方创建并命名第二条对话，新聊天为空，原聊天保留；两条对话能读取同一份课程资料、计划和课件，编辑结果刷新后共享。
- [ ] 新对话继承项目默认模型、提示词与 Skills（包括已关闭的可选 Skill）；更改单条对话不改变其他对话。显式保存为项目默认后，后续新对话继承新默认。
- [ ] 普通任务可创建项目文件夹，普通对话可移入或移出；项目外“新建独立对话”保持空白，不自动恢复刚才的课程聊天。
- [ ] 对话创建失败后重试同一请求不产生多个空聊天；服务重启后项目、成员、默认设置与原有审批全部保留。
- [ ] PDF 可直接在页面预览，另有下载按钮；在浏览器启用“始终下载 PDF”时仍能看到实际页面内容，并滚动、跳页和缩放，不触发下载。不能只检查 iframe 是否存在。
- [ ] 点击编辑 TeX 后必须看到已保存源码全文，保存后源码仍可见，关闭重开一致；课程概要不含源码的真实接口也必须通过。支持暂存、保存新版本并重新编译。两个编辑窗口同时保存时，旧版本不能覆盖新版本，旧 PDF 不能当成新稿的编译结果。
