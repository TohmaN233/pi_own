# Executable R Markdown

Examples must have reproducible seeds, assumptions, uncertainty estimates and meaningful numerical checks. Compare methods fairly on stated computational cost. Treat fitted coefficients and correlated draws honestly. Use analytical or independent boundary checks when available; a computation is not its own mathematical oracle. Distinguish a saved code listing, executed knitr output and rendered output. Rendering requires qualified Pandoc; knitting does not. Internal material IDs and workflow labels do not belong in visible prose.
