# Course Builder non-claims

The merged checkpoint must not be described as providing:

- pixel-faithful PowerPoint editing;
- editable PPTX export;
- complete preservation of slide masters, animation, SmartArt, native charts, or exact object placement;
- a general arbitrary-code sandbox;
- operating-system or container isolation for TeX;
- automatic screenshot-based visual acceptance;
- completed physical Teacher/Student package separation.

These are future milestones. The current checkpoint is for bounded semantic material import, versioned course planning, teacher-gated Beamer authoring, hardened compilation, deterministic supported visual artifacts, and explicit human review.
