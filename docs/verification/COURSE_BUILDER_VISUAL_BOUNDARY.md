# Course Builder visual boundary

Course Builder may request the existing fixed VisualHost renderers and bind validated artifacts to a lesson/deck revision. A visual result must include its structured specification, deterministic data, trace, artifact hash, and validator result. The agent must describe what the learner observes and what conclusion the observation supports.

The checkpoint does not claim arbitrary HTML/JavaScript execution, arbitrary mathematical code execution, automatic screenshot approval, or complete accessibility validation. Human slide-by-slide visual inspection remains part of the acceptance checklist.
