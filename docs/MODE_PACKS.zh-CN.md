# Mode Pack 使用与自定义

Mode Pack 是 Pi 的用途预设：一次选择会替换当前用途的提示词、Skill、插件或包、工具、工作流、上下文绑定和界面能力。它不是把一段自由文本不断追加到旧提示词后面。

内置模式规划包括教育讲解、教育练习、Teach-back、Visual Lab、Coding、创作和通用模式。旧的 `student-learn` 与 `practice` 标识继续作为兼容别名保留。

自定义 Mode Pack 必须发布为新版本。已经开始的会话继续使用原来的内容 Hash；修改不会悄悄改变正在进行的会话。必需资源缺失时不能启动；可选资源缺失会明确显示降级原因。跨角色或跨上下文类型的切换使用新会话。

自定义提示词与 Skill 都按用户资料处理，不能扩大工具权限、越过课程或工作区边界，也不能覆盖系统与安全规则。建议先复制最接近的内置包，只修改用途说明和可选 Skill，不要把所有 Skill 都设为必需。
