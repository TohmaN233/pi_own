# 螺旋式重访

本 Skill 只在一个概念再次出现时启用。重访必须回答：这一次比上一次多了什么结构？

## 每次重访记录

- **保留**：哪些已有理解无需重讲；
- **增加**：新增了什么变量、条件或机制；
- **重组**：哪些孤立认识形成了新的关系；
- **表征变化**：是否从操作、图像、语言或符号之间转换；
- **边界与反例**：适用条件在哪里失效；
- **迁移距离**：是否进入了更陌生的情境；
- **下一目标**：下一次重访准备增加什么。

## 假螺旋

以下情况不是螺旋：只换术语、只增加题目难度、只在结尾复习、用完全相同的情境和表征重讲、每课都是新内容而旧概念从不回来。

## 机器边界

ConceptLearningRecord 的重访至少必须在 `added`、`reorganized`、`boundaries`、`representationShift` 或 `transferDistance` 中留下增量。没有增量时以 `REPEATED_NOT_SPIRALED` 拒绝发布。
