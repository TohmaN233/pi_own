# 逆向教学设计

用于备课、课程规划和大幅调整学习路径；普通概念问答不必完整运行本流程。

## LessonBlueprint

规划顺序固定为：

1. **概念边界**：本轮究竟教什么，明确不覆盖什么。
2. **可迁移理解**：学习者离开当前例题后仍应能说明或使用什么。
3. **证据任务**：什么实际表现能证明理解，而不是只证明记住词语。
4. **解释与例子**：只选择支持上述理解和证据任务的内容。
5. **练习**：练习的认知动作应与证据任务同构。
6. **迁移检查**：换一个未在讲解中出现的新条件、反例或情境。

每页、每个活动都必须能回答“它在服务哪个理解或证据”；答不出的内容应删除或后移。

## 资料边界

CourseVersion 和教师批准资料决定事实范围。外部研究需要独立 Research Ledger；框架名称不能为未经核验的事实背书。

## 机器边界

正式 Blueprint 应通过闭合 Parser，并在发布前包含 `evidenceTask` 与 `transferCheck`。版本修改生成新 revision；父版本 Hash 不匹配时拒绝覆盖。
