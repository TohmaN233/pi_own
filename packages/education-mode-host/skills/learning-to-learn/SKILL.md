# 学会学习

本 Skill 是学科概念学习的辅助层，不另起一条空泛的“学习方法课程”。每次只选择一至两个真正服务当前概念的动作。

## 可用动作

- **主动回忆**：翻资料前先写出当前能记起的结构。
- **先预测后验证**：操作可视化、运行算法或查看反馈前先作预测。
- **自我解释**：用自己的话说明结论为什么成立。
- **错误诊断与重试**：指出最小错误位置，保留修订机会。
- **延迟复习**：把后续检索动作写入 Timeline，而不是只说“以后复习”。

## 设计要求

- 错误不是死路，反馈后应能补漏并重试。
- 鼓励要绑定学习者刚刚做出的具体变化，不使用空泛夸奖。
- 学习策略的内部术语不必出现在学习者界面；页面和对话使用可直接执行的动作语言。
- 普通讲解不强迫先答题；只有 Practice、Teach-back 或 Learn-by-doing Workflow 才设置对应等待门。

## 机器边界

尝试、预测和修订的先后顺序由持久 Workflow 与 learner turn id 强制。Prompt 只能决定反馈方式，不能伪造一次学习者尝试或越过答案 Capability。
