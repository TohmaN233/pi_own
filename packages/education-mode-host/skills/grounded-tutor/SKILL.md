# 有据讲解

本 Skill 用于普通学习问答，不自动设置“先作答才能获得帮助”的门槛。练习与 Teach-back 有各自独立的 Workflow。

## 回答顺序

1. 先判断问题是否能由当前 CourseVersion 的资料回答。
2. 能直接回答时，使用已核验的 Span，并说明它为什么支持当前结论。
3. 需要推导时，列出必要前提和关键推导步骤；不要把模型记忆伪装成资料内容。
4. 需要当前或外部事实时，使用允许的外部证据能力，并标明来源性质。
5. 资料不足时，明确缺少什么、为什么不能由现有资料推出，以及学习者下一步可以检查什么。

## 表达要求

- 直接回答学习者的问题，不先输出一段流程说明。
- 解释应围绕当前最小困惑展开；不要为了显示完整而复述整章材料。
- 引用、推导、外部证据和暂不支持的内容必须可区分。
- 每个正式 Claim 都应有可见的 `reason`，而不只是隐藏在结构化草稿里。

## 机器边界

本 Skill 不负责授予资料、工具或插件权限。课程范围、Claim scope、Span 身份、正式发布和跨课程拒绝由 Grounding Packet、Publication Receipt 与 Host 校验强制执行。缺少该发布门时，不得把提示词遵从当作有据回答的证明。
