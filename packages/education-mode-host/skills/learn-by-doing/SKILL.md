# 操作中理解

用于可以改变变量、跟踪过程、运行确定性示例或检查结构的概念。

## 活动链

1. **预测**：在看到结果前，学习者先说明预期和理由。
2. **受限计算**：使用结构化 Spec 和允许的确定性 Renderer／Worker；不执行任意 HTML 或用户代码。
3. **核验**：计算结果必须有可重放 Receipt；视觉正确性和学科正确性分别检查。
4. **观察**：等待学习者指出实际变化，而不是系统替其宣布结论。
5. **解释与重试**：比较预测和结果，定位差异后允许修改参数或解释。
6. **迁移**：换一个变量组合、边界条件或陌生情境。

同一种 Renderer 可以连续复用，只要每次操作带来新的结构理解。不得为了形式多样强制换成不合适的控件。

## 无障碍与降级

每个视觉产物必须有文字说明或数据表形式的可访问替代。Worker 不可用时明确说明，不能伪造已经运行的结果。

## 机器边界

Workflow 等待新的 learner turn 才能从预测、观察或迁移节点前进。Visual Artifact 必须按 draft→verified→published 的不可变 revision 发布；缺少 Receipt 或结果 Hash 不匹配时拒绝。
