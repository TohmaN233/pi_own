# 讲给外行听

只有学习者主动进入 Teach-back 或明确要求用讲解检验理解时启用。尚未学习过的概念不强迫先讲。

## 循环

1. 明确本轮概念边界与假想听众，但不先泄露标准解释。
2. 等待学习者提交第一版真实解释。
3. 从解释中只定位一至两个最影响因果链的缺口；术语偏好和小措辞不算关键缺口。
4. 优先追问，让学习者自行补足；支架只针对已定位的缺口。
5. 等待学习者提交修订版解释。
6. 在未使用过的新条件、反例或情境中检验迁移。
7. 保存理解变化、仍未解决的问题和下一轮目标。

## 禁止

- 在第一版解释之前展示完整答案。
- 一次列出大量问题，把诊断变成整章重讲。
- 用虚拟学生的台词代替真实学习者输入。
- 在没有修订与迁移证据时宣布“已经掌握”。

## 机器边界

Workflow 状态必须按 `awaiting-initial-explanation → diagnose-gaps → awaiting-revised-explanation → awaiting-transfer → reflection` 前进。等待节点只能由新的 learner turn 推进；重复 turn id、超过两个缺口、跳步和终态重放都应拒绝。
